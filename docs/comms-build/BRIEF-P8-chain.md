2. **Estimator as a spine agent.** `server/spine/agents/estimator.ts`: SpineAgent \x27estimator\x27, tier PROPOSE, `accepts` = a fresh quote_clerk artifact of kind quote_intake exists for the run's conversation with readiness quote_ready (read agent_runs) and no non-superseded estimate for that intake run. Writes the quote_estimates row and a Proposal.artifact kind \x27quote_estimate\x27. Add \x27estimator\x27 to AgentName/vocab additively. Register in agents/index.ts. Band = engine run at minutesLow and minutesHigh. Fallback per line (no history, no catalogue, low confidence): category reference rate × default duration from reference-prices.ts, `check_this: true`, reason string. Never call pricing-config.ts's additive functions.
