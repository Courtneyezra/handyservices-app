## Build
1. **agent_runs table.** Migration + schema: `agent_runs(id text pk, agent text, pack_id text, pack_version int, trigger text, conversation_id uuid null, case_file_ref text null, model text, model_snapshot text, prompt_hash text null, decision text null, lane text null, proposal jsonb null, guards_hit text[] default '{}', usage jsonb null, cost_pence int null, duration_ms int null, transcript_ref text null, error text null, started_at timestamptz default now(), finished_at timestamptz null)` + index on (conversation_id, started_at desc).
2. **Runner persists runs.** In `server/agents/runner.ts` `runAgent` creates the row at start (id = newRunId('run') unless opts.runId given), and updates finished_at/usage/cost/error/transcript_ref at the end. cost_pence from usage × model price (Haiku 4.5 $1/$5, Sonnet 5 $2/$10, Opus 5 $5/$25 per MTok, cache reads 10%; 1 USD = 0.78 GBP). Expose the run id to tools via the opts/context so comms.ts, quote-prep.ts, recovery.ts, sla-sweep.ts, promise-tracker.ts pass it as `runId` when they queue drafts, raise flags, set tags, or call sendCustomerMessage. Any call that today generates an ad-hoc newRunId inside an agent should use the agent's run id instead.
3. **run_id columns.** `message_drafts.run_id text null`, `agent_questions.run_id text null`, `nudge_queue.run_id text null` (migration + schema). `queueDraft`, the flag path, and `queue_nudge` write it.
4. **Write-at-source ledger.** Extend `comms_events` with the new event types from §3.7 (`draft_created, draft_approved, draft_edited, draft_sent, draft_rejected, flag_raised, flag_closed, flag_expired, run_started, run_finished, sample_reviewed`) and a `run_id` column if missing. New module `server/ledger.ts` exporting one `appendEvent(e)` (insert, onConflictDoNothing on the existing unique ref index) and typed helpers. Call it from: `sendCustomerMessage` (message_out + draft_sent when a draft id is known), `queueDraft` (draft_created), `approveAndSendDraft` (draft_approved / draft_rejected / draft_edited when body differs), flag raise/close, and runner start/finish. Keep `syncCommsLedger` as backfill; add `ledgerDriftCheck()` that compares event counts vs source tables for the last 7 days and returns the delta (cron wiring is pane B's).
5. **Tests.** vitest unit tests for cost computation and for appendEvent idempotency using a fake db (no live DB). tsc clean.
